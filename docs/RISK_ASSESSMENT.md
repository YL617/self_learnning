# 法律风险与可行性检测报告

> 检测对象：《AI智学管家项目开发目标文档V9.0》与合并后的 V8.0 功能设计（见 [FEATURE_RECONCILIATION.md](./FEATURE_RECONCILIATION.md)）。
> 检测日期：2026-08-06。
> 声明：本报告为项目合规自检，不构成正式法律意见；正式公开运营前应咨询专业律师并确认最新法规。

## 结论

整体可以继续开发，**没有“完全无法实现”的单项功能**，但存在 3 项高风险、4 项中风险需要整改，另有 3 项设计在当前阶段不应作为可验证承诺。

## 一、法律与合规风险

| 风险点 | 触发环节 | 法规/平台规则 | 严重度 | 整改建议 |
| --- | --- | --- | --- | --- |
| 公开课程聚合版权 | B站/MOOC/Coursera 索引、章节映射、外链 | 著作权法、反不正当竞争法；平台条款 | 高 | 只展示“课程名称 + 外链”，不存储视频、不直链、不下载、不抓取章节内容；章节映射改为人工/半自动，必要时取得课程方授权 |
| 学生个人信息与教务数据 | 学情画像、成绩、挂科预警、B 端教务处看板 | 个人信息保护法、数据安全法 | 高 | 最小化收集；成绩与预警名单按敏感个人信息处理，需学校书面授权与数据处理协议；看板数据脱敏、目的限定；注销与导出功能必须实现 |
| AI 生成内容合规 | 计划、题目、解析、宠物对话等公开服务 | 《生成式人工智能服务管理暂行办法》第十七条、算法备案要求 | 高 | 公开上线前评估“是否具有舆论属性/社会动员能力”，必要时完成安全评估与备案；接入敏感词过滤与内容安全服务 |
| AI 内容标识 | 所有 AIGC 输出 | 《人工智能生成合成内容标识办法》（2025 年施行） | 中高 | 对 AI 生成的计划、题目、解析、文案增加显式标识，并在服务端保留隐式标识 |
| 绝对化宣传承诺 | V8.0 答辩话术“100%准确”“绝对正确” | 广告法、反不正当竞争法 | 中高 | 删除“100%”“绝对正确”等表述，改为“经四重质检”“持续优化准确率” |
| 虚拟币与付费体系 | 智学币、请假条、寻回卷轴、Pro/终身买断 | 消费者权益保护法、未成年人保护；虚拟财产规则 | 中 | 现阶段智学币只能通过学习行为获得，不开放真实货币购买；若未来收费，优先会员订阅，不做“买币抽奖/盲盒” |
| 微信消息推送 | 每日定时督促、长期订阅 | 微信开放平台规则：教育类目当前不开放“长期订阅模板” | 中 | 改为“站内通知 + 邮件 + 一次性订阅消息”；不能把“每天推送”作为可承诺功能 |
| 用户上传资料版权 | 用户上传 PDF/Word/PPT 供 AI 出题 | 著作权法；平台避风港规则 | 中 | 上传时声明用户拥有权利；文件仅临时用于出题；提供侵权投诉与删除通道；定期清理 |
| 代码沙箱滥用 | 用户提交任意代码执行 | 网络安全法、刑法（恶意代码） | 中低 | 接入 E2B/Piston，配置限流、超时、熔断与审计；用户协议明确禁止恶意代码与滥用 |
| 第三方模型数据处理 | 把资料、作业、画像发送给 DeepSeek/通义/GLM/E2B | 个人信息保护法、数据安全法 | 中低 | 隐私政策披露第三方处理；发送前数据最小化、脱敏；敏感信息获取单独同意 |
| 内容素材授权 | 白噪音、宠物音效、海报模板 | 著作权 | 低 | 使用免版权或已授权素材并保留授权记录 |

## 二、可行性风险（是否无法实现）

| 设计 | 检测结论 | 建议 |
| --- | --- | --- |
| “AI 答案 100% 正确”“四重质检保证绝对正确” | 无法实现 | 改为“质检后推送 + 用户反馈修正”，只承诺降低错误率 |
| 单机 5000 并发 / 10 万级用户 | 2 核 4G 单机无法验证 | 删除未验证数字，改为“架构预留 Redis 缓存、消息队列与水平扩展能力” |
| 微信“长期订阅 + 每日推送” | 教育类目当前不开放长期订阅模板 | 用一次性订阅消息、站内通知和邮件替代 |
| 全量知识图谱 + B站视频自动章节映射 | MVP 内成本过高 | 用“学科→章节→知识点→标签”四级标签 + 半自动映射 |
| 经典测试理论（CTT）区分度 | 小样本无统计意义 | 先记录正确率等统计字段，数据量足够后再启用 |
| 强化学习动态优化计划 | 数据与算力不足 | V9.0 已改为“专家模板 + AI 调整 + 行为规则”，正确 |
| 小程序端挂机检测 | 小程序无法检测鼠标/键盘 | Web 端做交互活跃度检测；小程序端检测页面切后台与触摸事件 |
| 联网搜索补全 | 需要第三方搜索 API 与成本控制 | 可实现，放到 M6 后增强 |
| 自建 Docker/K8s 代码沙箱 | 开发成本过高、安全风险大 | V9.0 已改为接入 E2B/Piston，正确 |
| 破冰问卷、OCR、交互式出题菜单、宠物进化 | 均可实现 | 按里程碑推进，OCR 与联网搜索放第二阶段 |

## 三、必须整改清单

- [ ] 删除 V8.0 答辩话术中“100%准确”“绝对正确”等绝对化表述
- [ ] 课程聚合仅保留“名称 + 外链”，不存储视频、不直链、不爬取章节内容
- [ ] 增加用户协议、隐私政策、文件权利声明、侵权投诉与账号注销流程
- [ ] 对 AI 生成内容增加显式标识与敏感词过滤
- [ ] 提醒方案改为站内通知 + 邮件 + 一次性订阅消息
- [ ] 并发与规模表述改为“架构预留扩展”，不写未验证数字
- [ ] 智学币不开放真实货币购买
- [ ] 公开上线前确认生成式 AI 服务备案义务

## 四、结论

项目不存在“无法实现”的单项设计，核心风险集中在**版权、学生数据、AI 内容合规与微信推送限制**四类。按上述清单整改后，可以继续按 V9.0 框架推进 MVP。
