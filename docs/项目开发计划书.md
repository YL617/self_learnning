## 1. 项目概述

AI智学管家是一款面向高校学生的 AI 驱动型学习管理平台，围绕“学习规划—知识学习—智能练习—错题反馈—行为激励”闭环，利用大语言模型、RAG 检索增强和学习行为分析技术，为学生提供个性化学习辅助。

项目解决四类问题：

1. 不知道学什么：AI 根据用户目标生成学习计划。
2. 不知道怎么学：结合知识体系提供学习路径。
3. 学完不会巩固：AI 生成针对性练习并管理错题。
4. 难以坚持：通过专注管理和游戏化激励提高学习持续性。

技术架构以 V9.0 为唯一基准；V8.0 中更全面的功能设计（学情画像、知识标签、四重质检、复习调度、宠物经济、交互式文档出题等）以不冲突为前提纳入本计划。

## 2. 技术架构基准（V9.0）

| 层次 | 技术选型 | 说明 |
| --- | --- | --- |
| Web 端 | Vue3 + TypeScript + Vite | 主力演示端 |
| 移动端 | Uni-app 微信小程序 | 一套代码编译 H5 与微信小程序 |
| 后端 | FastAPI + SQLAlchemy 2.x + Pydantic v2 | REST API，自动 OpenAPI 文档 |
| 数据存储 | MySQL + Redis | 业务主存储与缓存/队列 |
| 定时任务 | Celery + Redis | 文档解析、提醒、复习调度 |
| AI 能力 | AI Gateway（DeepSeek/通义千问/GLM） | 统一模型调用、路由与降级 |
| RAG | LlamaIndex + Chroma/Milvus | 文档解析、切片、向量检索 |
| 部署 | Docker Compose | 2 核 4G 云服务器演示环境 |

框架约束：不引入多租户 Tenant ID、Tauri/Electron、Flutter、K8s、LangChain 绑定或单模型绑定。

## 3. 功能范围

### 3.1 MVP 主链路

注册登录 → 1 分钟破冰问卷 → AI 生成学习计划 → 按计划学习 → AI 出题练习 → 四重质检 → 错题沉淀与复习调度 → 番茄钟专注 → 宠物成长激励。

### 3.2 MVP 功能清单

| 模块 | 功能 | 优先级 |
| --- | --- | --- |
| 用户 | 注册、登录、JWT、资料、账号注销与数据导出 | P0 |
| 冷启动 | 1 分钟破冰问卷、专家模板 + AI 微调 | P0 |
| 学习规划 | AI 生成周计划、难度梯度、Buffer、动态调整日志 | P0 |
| 练习 | AI 出题、判题、四重质检、知识标签 | P0 |
| 错题 | 自动沉淀、艾宾浩斯复习调度、举一反三、反馈 | P0 |
| 专注 | 番茄钟、防作弊/防沉迷、学习统计 | P0 |
| 宠物 | 等级/经验/心情/饱食度、智学币经济、Combo | P0 |
| 文件出题 | 多格式解析、交互式题型菜单、基于文档出题 | P1 |
| 效能 | 待办、可视化日历、周报/月报 | P1 |
| 提醒 | 站内通知、邮件、一次性订阅消息 | P1 |
| 课程聚合 | 课程索引与外链、大纲映射 | P2 |
| 代码沙箱 | 接入 E2B/Piston，自动判分 | P2 |

### 3.3 非 MVP 范围

- 图片 OCR 与联网搜索补全（第二阶段）
- 微信长期订阅消息（平台当前不开放教育类长期订阅）
- 复杂强化学习、多智能体编排
- 多租户、10 万级用户集群

## 4. 里程碑计划（8 周）

| 里程碑 | 周期 | 主题 | 核心产出 | 验收标准 |
| --- | --- | --- | --- | --- |
| M0 骨架 | 第 1 周 | 基础设施 | 前后端骨架、MySQL/Redis、Docker | 三端可启动，接口文档可访问 |
| M1 用户 | 第 2 周 | 用户与冷启动 | 注册登录、资料、破冰问卷 | 注册后 3 秒内生成第一份计划 |
| M2 规划 | 第 3-4 周 | AI 学习规划 | 模板 + AI 调整、动态调整 | AI 不可用时仍可生成计划 |
| M3 练习 | 第 4-5 周 | 出题与错题 | 四重质检、知识标签、复习调度 | 错题按 1/3/7/15/30 天进入复习 |
| M4 文件 | 第 5-6 周 | 文件出题 + RAG | 交互式菜单、配额、向量检索 | 50 页内 PDF 可解析并出题 |
| M5 激励 | 第 6-7 周 | 专注与宠物 | 完整币经济、防作弊/防沉迷 | 完成任务/专注可看到金币与经验变化 |
| M6 演示 | 第 7-8 周 | 联调与部署 | 日历/提醒/课程聚合、演示数据 | 2 核 4G 服务器完成部署与演示 |

## 5. 任务拆分

### 5.1 M1 用户系统与冷启动

- 注册、登录、JWT 鉴权与 401 统一处理
- 用户资料编辑与破冰问卷页面
- 问卷数据写入 `user_profiles`
- 专家模板库与 AI 微调生成破冰周计划
- 隐私政策、用户协议、账号注销与数据导出入口

验收：新用户注册后完成问卷即可获得第一份周计划；无 API Key 时使用模板兜底。

### 5.2 M2 AI 学习规划

- 学习画像字段扩展与画像持续更新
- 难度梯度、精力匹配与 20% Buffer
- 连续未完成任务自动拆分或降低难度
- 计划调整日志与前后对比

验收：同输入重复生成结果稳定；行为数据可触发计划动态调整。

### 5.3 M3 出题与错题

- 出题 Prompt 与结构化输出
- 四重质检：RAG 约束、AI 自检、格式规则、用户反馈
- 知识标签体系与个人热力图
- 判题逻辑、错题自动沉淀
- 艾宾浩斯复习调度与举一反三
- 题目反馈与人工复核状态

验收：题目包含题干/选项/答案/解析；错题可复习、可掌握、可反馈。

### 5.4 M4 文件出题与 RAG

- 多格式解析（PDF/Word/PPT/TXT）
- AI 预分析并返回交互式题型菜单
- 文件配额、临时存储清理、内容安全校验
- 文本切片、Chroma 向量化与检索
- 基于检索上下文出题

验收：上传文件后可选择题型组合并生成题目；超限文件被拦截并提示。

### 5.5 M5 专注与宠物

- 番茄钟开始/结束/统计
- Web 端交互活跃度检测，小程序端切后台检测
- 每日番茄钟收益上限与连续专注提醒
- 智学币完整经济（任务/专注/Combo/错题消灭/消费）
- 宠物等级、经验、心情、饱食度、进化与道具

验收：完成一次番茄钟或答题可看到金币、经验与饱食度变化；挂机不计时。

### 5.6 M6 联调与部署

- 待办、可视化日历、学习周报/月报
- 站内通知、邮件与一次性订阅消息
- 公开课程索引与外链
- 演示账号与演示数据
- Docker Compose 部署与部署文档
- 答辩 PPT、架构图、录屏

验收：演示环境完整跑通主链路；核心页面无报错；数据可演示。

## 8. AI 能力接入顺序

1. Phase A：DeepSeek 直接调用，跑通规划与出题。
2. Phase B：AI Gateway 多模型与降级，接入通义千问、GLM。
3. Phase C：RAG 文档解析与向量检索增强出题。
4. Phase D：联网搜索补全与代码沙箱判分。

所有 AI 调用保留离线模板降级，保证演示现场不因网络或额度中断。

## 10. 合规与风险

项目已按 [RISK_ASSESSMENT.md](./RISK_ASSESSMENT.md) 完成检测。必须整改项：

- 删除“100%准确”“绝对正确”等绝对化表述
- 课程聚合仅保留“名称 + 外链”，不存储视频、不直链、不爬取章节
- 增加用户协议、隐私政策、文件权利声明与侵权投诉通道
- AI 生成内容增加显式标识与敏感词过滤
- 提醒方案改为站内通知 + 邮件 + 一次性订阅消息
- 智学币不开放真实货币购买
- 公开上线前确认生成式 AI 服务备案义务
