# 共享题库入口实施与验证

日期：2026-10-17；发布前复验：2026-10-19。状态：本地实现已验证；未发布生产。此前独立审核通过，用户现已要求停止审核对话回传。

用户在台账清点期间明确要求转入升级开发，并确认开始实现用户共享题库入口。本次任务按该最新授权执行，不要求先验收全部台账。

## 交付

- 新增 `/question-bank` 页面及侧边栏入口，智能练习页提供互相跳转入口。
- 复用 `GET /api/v1/question-bank`，按学科、知识点、难度筛选；查询条件保存在URL中，支持刷新、深链和浏览器返回。
- 普通知识点列表只选择 active concept；名称加载失败可单独重试，不阻断题库读取。
- 列表不展示参考答案。开始练习后复用现有 `QuestionCard`，提交成功后可查看答案解析，返回列表；不提供收藏、删除或关联管理控件。
- 空态、请求失败、无效筛选和加载态分开；过期请求不覆盖新筛选结果。
- 每次最多获取100题，达到上限明确提示缩小筛选范围，不伪造全库总数或分页。
