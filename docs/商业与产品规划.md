# AI智学管家：商业与产品规划（含 M0 最快可用版）

> 版本：V1.0，日期：2026-08-10

## 1. 理论模型

- 单用户月毛利 = 会员价 −（AI 成本 + 服务器成本 + 渠道/支付成本）
- 免费试用是获客成本，必须用每日 AI 调用上限兜底
- 三档会员按功能分层，权限必须在后端控制
- 个人备案不直接站内收款，M0 采用“闲鱼卖激活码 + 官网兑换 + 后台开通”
- 产品定位：AI 学习陪伴 + 智能练习 + 错题复习 + 专注激励

## 2. M0 最快可用阶段

形态：个人 ICP 备案免费体验站 + 闲鱼卖激活码 + 后台手动开通，官网不直接收款。

部署：阿里云/腾讯云 2 核 4G 国内服务器，Docker 部署 FastAPI + MySQL + Redis + Web。

功能范围：

- 保留现有学习计划、智能练习、错题本、专注、宠物、文件出题、课程、AI 对话
- 注册后 7 天全功能免费试用
- 免费档每日 20 次 AI 调用上限
- 三档会员权限控制
- 激活码月卡/季卡/年卡（30/90/365 天）
- 后台用户管理 + 激活码生成/撤销 + 手动开通
- DeepSeek 余额与用量监控
- 基础敏感词过滤 + AIGC 标识 + 隐私政策/用户协议

明确不做：站内支付、自动答题、完整内容管理后台。

## 3. 会员体系

| 档位 | 价格 | 权益 |
| --- | --- | --- |
| 免费（试用结束后） | 0 | 总览、基础宠物、每日 20 次 AI 调用 |
| 基础会员 | 10 元/月 | 智能练习 + 错题本 |
| 进阶会员 | 20 元/月 | 基础会员 + 学习计划 + 专注模式 + 宠物完整功能 |
| 完整会员 | 30 元/月 | 进阶会员 + 文件出题 + 优先模型 |

试用规则：注册后 7 天内开放全部功能；试用结束后回到免费档。

额度规则：免费档每日 20 次；基础 60 次；进阶 120 次；完整 300 次，可在验收后按 AI 成本调整。

## 4. 激活码与会员有效期

- 新增 `activation_codes`：code、tier、days、status、created_by、used_by、used_at
- `users.membership_expires_at`：会员到期自动降级
- 兑换接口：`POST /users/me/activate`
- 后台：生成、撤销、查看使用记录

## 5. 数据模型与接口

- `users` 新增：`membership_expires_at`
- 新增 `ai_daily_usage`：user_id、usage_date、calls
- 新增 `activation_codes`
- 新增 `ai_provider_snapshots`、`ai_usage_records`
- AI 额度校验：`require_ai_access`，接入计划、出题、文件出题、宠物对话等 AI 入口
- 管理员接口：
  - `GET/POST /admin/ai-monitor`
  - `GET/POST /admin/activation-codes`、`POST /admin/activation-codes/{id}/revoke`
  - `GET/PATCH /admin/users`
  - `GET /admin/stats/overview`

## 6. 合规与内容安全

- 个人 ICP 备案只做非经营性展示 + 激活码模式，官网不直接收款
- 页面增加 AIGC 标识、隐私政策、用户协议、敏感词黑名单
- 若未来走站内支付，必须先注册个体工商户并申请 ICP 经营许可证，再接入微信/支付宝商户
- DeepSeek 用量监控用于成本与风险预警

## 7. 开源许可策略

- 只整合 MIT / Apache 2.0 / BSD
- GPL / AGPL 源码不引入项目
- 闭源能力只用云 API（TTS、OCR、内容安全、支付），不进仓库
- 新增 `THIRD_PARTY_NOTICES.md` 记录来源、版本、许可证
- API Monitor（MIT）的 DeepSeek 监控逻辑已移植

## 8. 验收标准

- 注册 → 7 天试用 → 免费档额度生效
- 激活码兑换 → 对应档位权益立即生效，到期自动降级
- 免费用户第 21 次 AI 调用被拦截并提示升级
- 管理员能生成/撤销激活码、调整用户会员、查看 AI 余额与用量
- 非管理员访问 `/admin` 返回 403
- 后端 pytest、ruff、Web 构建、Vitest、小程序类型检查全部通过
- 国内服务器部署完成，备案页与域名可访问
