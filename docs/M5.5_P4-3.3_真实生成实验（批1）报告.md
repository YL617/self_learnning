## 3. 门禁拦截分析（本轮最重要发现）

### 3.1 G5B 拦下 9 题：**批级属性误伤单题**

`evaluate_answer_distribution()` 的语义是：批内各答案字母占比须落在 [20%, 30%] 且用满 ≥4 个字母；命中时，`assemble_manifest()` 把责任落到**"占比越界的字母"对应的题**上（`p43_gates.py:522-541`）。

本批实测：A=25%、B=30%、**C=45%**（越界）、**D=0%（未使用）** → `offenders=["C"]` → **全部 9 道答案为 C 的题被判 FAIL**。

**三处逻辑问题（按严重度排序）：**

1. **责任错配**：真正更根本的问题是 **D 完全没被使用（0%）**，但 D 不在 `counts` 里 → **不进入 `offenders`**；责任反而全部落在 C 题头上。即"缺位"不指向任何题，"超配"却让 9 道题背锅。
2. **不自洽（治标不治本）**：这 9 道 C 题被剔除后，剩余 9 题变成 A=4（44%）/ B=5（56%）—— **依然严重越界**。G5B 的"惩罚"根本不能修复分布，只是删掉了一个字母。
3. **与初衷相反**：这些题**本身没有质量缺陷**（G1–G7 其余全过），却被记为 FAIL 并保留在清单里（依 P4-3.2 决策 D-3.2-2）。人工必须为每一条写 `推翻门禁` 备注（否则 `collect` 触发 E03）→ **人审负担不减反增**，与门禁"减少人审负担"的定位相悖。

> 本质：**"整批答案位置不均衡"是可以用机械手段修复的（选项洗牌），不应作为单题剔除理由。** 正确形态应是"批级提示 + 洗牌建议"，而不是"逐题 FAIL"。

### 3.2 G5 拦下 3 题：**选项长度极差比**阈值对"定量短选项"过敏

`gate_g5_option_quality()` 要求选项**最长/最短 ≤ 2.5**。本批 3 题命中，例如：

- 选项 `[e, 2e, n+e, n^2-e]` → 长度 1/2/3/5 → 极差比 **5.00** → FAIL

这类数据结构定量题的选项长度天然落差大，**题目本身正确**，属阈值过敏（原意是抓"正确答案明显更长"这一 AI 特征，但此处比对的是"全部选项极值比"，语义不同）。
