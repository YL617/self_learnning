# M5.5 P4-3.3.2 解析选项引用一致性修复报告

## 1. 问题

批1的 20 道题经过选项洗牌后，结构化答案与选项保持一致，但解析中的“正确答案为 A”“B 项错误”等字母引用仍指向洗牌前的位置。自动门禁只检查解析长度和补全指纹，因此未发现这一语义漂移。

## 2. 根因

`shuffle_options()` 重排了选项并重算 `answer`，却没有同步重映射 `analysis` 中的选项引用。G3 也没有校验解析明确声明的答案字母是否与 `answer` 一致。

## 3. 修复

- 洗牌时建立旧字母到新字母的映射。
- 同步重映射解析中的“正确答案为/是 X”“X 项”“X 选项”“选项 X”。
- 同步更新审核使用的 `raw_analysis`，保留原始语义和长度，只改变位置字母。
- G3 新增确定性校验：解析明确声明的答案字母与结构化答案冲突时直接阻断。
- 增加回归测试，覆盖冲突阻断、无显式字母解析、洗牌后引用重映射。

## 4. 批1复跑结果

- 候选题：20。

- 显式解析答案冲突：0。

- 生产题目变更：0。

## 5. 结论

本次修复解决的是生成管道的确定性一致性缺陷，不替代内容审核。批1仍需完成逐题内容复核后，才能生成审核决定并进入 Apply。
