## 1. 复跑方式（刻意隔离变量）

```bash
python scripts/generate_question_batch.py \
  --targets docs/M5.5_P4-3_生成目标_批1.json \
  --raw-dir docs/p43_raw/批1 \                # ← 复用批 1 已留档的 8 份真实响应
  --existing docs/M5.5_P4-3_现有题面快照.json \
  --out docs/M5.5_P4-3_题目供给清单_批1.json
```

- **离线重放**：`--raw-dir` 直接读 8 份已留档的 DeepSeek 原始响应 → **不调用 LLM、零 token 成本**。
  这样"前后对比"只反映**门禁改动**这一个变量，而不是"模型这次又吐了别的题"。
- 原始输出存档：`docs/p43_raw/批1/001..008.json`（内容与批 1 完全一致，可随时复核）。
- 确定性已验证：同一留档重放两次，manifest 除 `generated_at` 外**逐字节相同**。

## 3. 归因：11 道被拒题全部来自两条被误用的规则

| 规则 | 校准前拦题数 | 归因 | 校准后 |
|---|---|---|---|
| **G5B**（批级答案分布） | 9 | 全是"答案字母 = C"这一**批级属性**的连带惩罚；题本身 7 门全过 | 9 → **0**（改为批级提示） |
| **G5**（全局长度极差比） | 3（其中 1 题与 G5B 重叠） | 全是 `e/2e/n+e`、`n-i+1/n-i-1` 这类**定量短选项**的误伤 | 3 → **0**（改判"正确项显著长于干扰项"，且仅提示） |
| G1–G4 / G6–G8 | 0 | 本轮无确定性缺陷 —— 与批 1 判断一致 | 0 |

**其余 9 道"原本就 PASS"的题，校准后仍然 PASS**（无回归）。

## 4. 答案分布：洗牌治本

```
校准前（模型原样）      A 5 │ B 6 │ C 9 │ D 0     ← 3 个字母，C 占 45%，D 从未出现
独立随机洗牌（中间态）  A 6 │ B 3 │ C 2 │ D 9     ← 仍偏斜（D 45%）→ 说明"每题独立随机"不够
批内均衡洗牌（最终）    A 5 │ B 5 │ C 5 │ D 5     ← 恰好均匀，G5B 提示消失
```

洗牌只动**选项顺序与答案字母**，不改题干/选项正文/解析/难度：
`P43-01-001` 选项从 `[e, 2e, n+e, n²-e]` 变为 `[n+e, e, 2e, n²-e]`，答案 B → C。
